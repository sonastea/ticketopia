# Documentation guidance

- Load only documentation relevant to the current task. Use `docs/README.md` to
  locate feature guides.
- Read change history only when historical context is needed. Search filenames
  or content to find relevant records; do not bulk-read `docs/changes/`.
- For notable changes, update the relevant guide and add a concise record at
  `docs/changes/YYYY/YYYY-MM-DD-short-title.md`. Link to guides instead of copying
  their contents into the record.
- Keep `docs/CHANGELOG.md` to one-line links for the 20 most recent records,
  newest first. Remove older links from that index, but retain their record files
  in the year directories.
