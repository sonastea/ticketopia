# Personalized radar

Mode: Operate. Local extension of the existing event collection/account surfaces.

## Direction contract

**THESIS:** Show a useful nearby event list whose every match is explained by an
explicit private choice, never a mysterious social score or fabricated relevance.

**OWN-WORLD:** Inherit the flat plum/light-stone shell, Manrope, dusty-rose date
indexes, image-led rows, native disclosure and visible outline focus. No new tokens.

**STORY:** Choose account city/category preferences or follows, see ranked matches
with reasons, open event details, save a choice, and refresh or paginate predictably.

**FIRST VIEWPORT:** Radar title, account-navigation links to location/categories/
follows, visible city/date scope and freshness evidence, then existing event rows
with readable reasons inside their event copy. Compact screens use Profile to reach
Radar, retaining the four-destination navigation. Empty/error states keep recovery
links in the task, without a decorative dashboard or invented statistics.

**FORM:** Code-led local extension of incumbent collections, inherited world seed
`6b2b9e52`; no concept tournament or design-system replacement.

**FINISH:** unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## Boundaries

Same shared service for web/API; no inferred interests, automatic notifications or
IP/browser-specific ranking. Native GET paging, detail links and existing protected
save/interest forms remain usable without JavaScript. No new shipping raster assets.
