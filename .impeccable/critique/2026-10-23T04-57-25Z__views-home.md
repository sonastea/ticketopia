## Priority Issues
- [P0] Unknown/tracking query params (utm_*, fbclid) return 400 with raw validator text on /, /community, event pages (internal/discovery/query.go:55, internal/recommendations/recommendations.go:180, internal/api/pages.go:136). Fix: ignore (or redirect away) unknown keys on HTML routes; keep strict /api/v1 and duplicate-known-key handling; human copy for real errors.
- [P1] Empty states are wrong in context and dead-end during the pilot: "Open an event to ask the first question" shown inside an event (discussions.templ:39, recommendations.templ:81/:172), "0 visible questions and tips". Fix: context-aware empty copy with the Ask/Recommend/Sign-in action as the CTA; reserve "on this page" for page ≥2.
- [P1] Compact Discover pushes the first event below the fold at 390×844 (stale banner + Partial coverage + Saves-are-private + orphan sort label); 5-item bottom nav (.6875rem labels) wraps to two rows at 320px; event section tabs wrap. Fix: one merged freshness line, move the privacy note to first Save, sort on the heading line, four-item or shorter-label bottom nav as docs specify.
- [P2] Rows lead with Ticketmaster policy boilerplate (more_events.templ:69-71); "Featuring X" repeats the title; "Upsell:" items listed as events. Fix: drop the row excerpt, hide self-referential Featuring, filter Upsell items.
- [P2] "Sign in to save" doesn't save (settings.templ:32-33). Fix: carry intent through sign-in and complete it, or relabel to "Sign in".
